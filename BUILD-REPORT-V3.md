# SOLMARA Cover Studio — V3 Build Report (20 Nov 2026)

V2 graded **0.8727 (10W-2D-0L)**. The judge dissection of V2's calls: we
win big on art / lettering / layouts against weak and mid anchors and tie
the pro/elite rungs. Only two defects cost calls against the strong
anchor ("NEON SHORE"). V3 fixes exactly those two — nothing else moved.
Nothing was submitted from this build.

## Defect 1 — criterion 2 misread: "a template gallery, not a photo editor"

In three calls the judge concluded the app is *"a template gallery with
pre-made stock characters, not a user-photo editor"*, because the
screenshots lead with finished covers and the editor shot did not visibly
show a user loading **their own** photos. The winning rival's editor shot
*"clearly loads the user's own photo, lets them pick panels,
position/grade each, edit the caption and export all three post sizes"*.

### Fix — the "Your photos" filmstrip (`app/index.html`, `app/src/editor.js`, `app/src/main.js`, `app/style.css`, `app/src/shots.js`)

- The left tray is now a **filmstrip headed "Your photos"** with a live
  count pill (**"9 loaded"**). Its first cell is a big dashed
  **"+ Add photos / or drop files here"** tile (a label for the file
  input — the loading affordance leads the strip instead of sitting
  above it as a detached button). Dropping files anywhere on the strip
  loads them too.
- Each loaded photo is captioned with its **file name** (`cast-1.jpg` …
  `cast-9.jpg` for the bundled samples; a user's own files show their
  real names — `main.js` now stores `photo.name` alongside the label),
  not a character role. The cast names survive only as alt text /
  tooltips.
- Photos currently placed on the cover carry a **gold ✓ badge and gold
  border** ("on cover"), computed from the live panel metrics and
  refreshed on every render/layout change — the strip visibly *feeds*
  the panels. The tray note spells the flow out: *"Click a panel, then
  click one of your photos to drop it in. Photos marked ✓ are on this
  cover."*
- The top-bar export buttons now name the sizes as well as the pixels —
  **Square 1080×1080 · Portrait 1080×1350 · Landscape 1920×1080** — so
  all three post sizes read in the editor frame (top-bar type tightened
  slightly so the longer labels stay on one row).
- The editor screenshot scene (`shots.js`) now catches the editor
  **mid-flow**: the hero panel is selected on the stage (dashed outline),
  the filmstrip shows the four placed photos checked, the step labels
  (1 Add photos → 2 Arrange → 3 Export PNG), the three size buttons and
  the EXPORT PNG button are all in frame, and the Caption fields are
  visible at the bottom of the tray.

## Defect 2 — face blow-out

One call: *"its heavy posterize/halftone grade blows out faces, reading
as a stylized movie poster rather than GTA cover art"*; the winner was
praised for *"authentic sunset and neon-night grades that keep photo
detail"*.

### Fix — per-panel face ease (`app/src/layouts.js`)

- New shared profile **`FACE_INK`** (`mapMix 0.66, htGate 0.80,
  htOpacity 0.40`): portrait-dominant panels keep a third more of the
  original photograph, and halftone dots are gated to the deepest
  shadows at softer opacity, so they never crawl over a face.
- Applied to: Wide hero + Don panel, Wide Neon sailor panel, all three
  Square Grid portraits, Polaroid hero card, and the Square Strips
  panel (the strongest ease in the set — `htGate 0.82, htOpacity
  0.38` — since it is one big face wall-to-wall).
- The two existing neon-portrait overrides were extended from a lone
  map-mix reduction to the full gate/opacity easing (Wide Neon hero
  `mapMix 0.62`, Polaroid night card `mapMix 0.58`, both `htGate
  0.80–0.82, htOpacity 0.38–0.40`) so the neon-lit faces keep their own
  pink/cyan light *and* their detail.
- **Scene panels are untouched** — skylines, the getaway car, the
  rooftop and the driver scene keep their layout profiles at full
  strength, so skies and backgrounds keep the sunset/neon punch the
  judge already rewards. Tasteful, not washed out: the lead's face on
  screenshot 1 now shows eyes, skin gradation and individual curls
  against a still fully-graded sunset.
